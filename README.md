# IQRA Tamil

IQRA Tamil is an independent foundation for a Tamil Muslim educational platform. The current foundation includes a polished landing page and the first complete Quran Challenge, available at `/challenge/quran-001`.

## Current scope

- Responsive landing page for Tamil-speaking learners, families, and communities
- Read / Learn / Grow positioning
- One in-page Quran Challenge route: `/challenge/quran-001`
- Exactly ten stable questions (`quran-001` through `quran-010`), sequential scoring, feedback, and results
- No additional challenge routes or challenge features
- No new dependencies added
- No authentication or database yet

## Development direction

Future application work can be built independently from this foundation, and persistent learning progress introduced as requirements become evident. 

## Run locally

Use the existing project scripts and dependency setup. The app is built with Next.js App Router and Tailwind CSS.
