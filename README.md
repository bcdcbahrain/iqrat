# IQRA Tamil

IQRA Tamil is an independent foundation for a Tamil Muslim educational platform. The current stage is intentionally limited to a polished landing page that introduces the mission and presents the Quran Challenge as a clearly non-functional “Coming Next” placeholder.

## Current scope

- Responsive landing page for Tamil-speaking learners, families, and communities
- Read / Learn / Grow positioning
- Quran Challenge teaser only — no route, question engine, scoring, or challenge implementation
- No new dependencies added
- No authentication or database yet

## Development direction

Future application work can be built independently from this foundation, and persistent learning progress introduced as requirements become evident. 

## Run locally

Use the existing project scripts and dependency setup. The app is built with Next.js App Router and Tailwind CSS.
